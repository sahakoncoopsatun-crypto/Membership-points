ตั้งค่าฐานข้อมูล Firebase Realtime Database

ทุกการเพิ่ม ลบ แก้ไข หรือเปลี่ยนสถานะสมาชิก จะซิงค์ขึ้น Cloud อัตโนมัติทันที

การตั้งค่าสิทธิ์ใน Firebase Console (Rules):

ใน Firebase Console > Realtime Database > แท็บ Rules กำหนดเป็น: 

{
  "rules": {
    ".read": true,
    ".write": true
  }
}
โครงสร้างข้อมูลในระบบ:
